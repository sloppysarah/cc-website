Caesar cipher encoder/decoder - works for letters, but not numbers. You can shift back/forward.
Railfence cipher encoder - encodes plaintext using transposition.
Playfair cipher encoder - encodes plaintext using a 5x5 grid (alphabetical order w/ i/j sharing a space). Decoding with it sort of works, but only if the letter pairs were encoded using the rectangle rule (not in the same row/column).
